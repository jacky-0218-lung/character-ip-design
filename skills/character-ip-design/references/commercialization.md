# Commercialization Reference（商業化：設計之後，IP 才開始）

Read this at Phase 3 for full-pipeline briefs. The deliverable here is a staged roadmap + KPI
sheet + licensing-readiness notes inside the IP bible — concrete enough that the user can
execute quarter by quarter.

## Rollout ladder（依驗證成本排序 — 每一階都是下一階的測試）

1. **商標申請/檢索確認**（先於任何公開曝光；Kumamon 海外被搶註是前車之鑑）
2. **貼圖 + 社群內容**（最低成本市場驗證：LINE Creators Market 首年就證明個人創作者可達
   ¥1億級；內容支柱見下）
3. **小物週邊**（貼紙/文具/壓克力 — San-X 的起家品類；市集/蝦皮試水温）
4. **絨毛/盲盒**（需打樣 gate，見商品化檢核；盲盒慣例 12+1 隱藏款、單價帶 NT$250–450 /
   RMB 79 / US$12.99 級距）
5. **授權/聯名**（需要 licensing style guide — 見下；Sanrio 的階梯是基本盤授權之上疊精品聯名）
6. **內容/空間**（動畫短篇、快閃店 — 遠期選項，roadmap 提一行即可）

Each rung's result gates the next: sticker sales + social growth justify merch; merch
sell-through justifies licensing conversations. Write the roadmap as 3 phases (0–3月 / 3–12月
/ 12月+) with the gate condition between each.

## 內容支柱（social content pillars, 3–4 個）

Derive from the character profile, not from marketing genericism: 習慣/怪癖 → recurring
gag format; 世界觀規則 → observational posts; 口頭禪 → caption system; 製作過程 → behind-
the-scenes (獨立創作者的隱藏優勢). Each pillar: name + example post + cadence.

## KPI sheet（挑 5–7 個，附檢查週期）

- 貼圖：下載數/送出數/營收（LINE 後台）
- 社群：追蹤成長率、互動率、分享/儲存數（IG/Threads/小紅書）
- 商品：市集/電商 sell-through、回購率、（盲盒）端盒率與二手溢價（POP MART 退役款二手溢價
  20–40% 是熱度訊號）
- 授權：洽談中/成交授權案數、權利金收入
- 粉絲：社群人數、UGC 數量（粉絲二創是 IP 活著的鐵證）
- 組合管理：若有多角色，人氣投票/互動佔比（Sanrio Character Ranking 模式 — 用數據決定資源）

## 商品化檢核（merch feasibility gates — 設計階段就要過）

- **印刷**：一色版存在且可看（設計流程已強制）；特別色/CMYK 對照表在設計書
- **絨毛**：single-fabric 可作、五官可刺繡、符號在 3D 上不消失（turnaround 或 plush note）
- **盲盒/公仔**：材質宣告（亮/霧）、分件可行、隱藏款與變體軸已在系列規劃定義
- **最小尺寸**：favicon/瓶蓋/吊牌尺寸的辨識已驗證（剪影測試的 64px 檢查）

## Licensing style guide readiness

授權方會要的东西（業界清單），IP bible 應已備齊或標注缺項：approved artwork library（本
pipeline 的 masters + exports）、logo/lockups、色彩規範（Pantone/CMYK 對照）、字體、使用規則
（clear space、禁改項 = Don'ts 章節）、行為規則與禁忌清單（worldbuilding 的 taboo list）、
co-branding 規則。缺哪項就在 bible 裡列為「授權前待補」。

## Honesty rules

- 數字要嘛有連結來源、要嘛標「估計」。roadmap 是計畫不是預言 — 每階寫 gate 條件而不是保證。
- 本節不是財務或法律意見；商標一節永遠帶「請洽商標師」聲明。
- 不要替使用者虛構預算/產能 — 不知道就用「若資源允許」分支寫。
